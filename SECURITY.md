# Security Policy

## Supported version

This archived course project only receives security fixes on the current `main` branch. Historical revisions are unsupported and may contain insecure examples or revoked credentials.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not include credentials, personal data, verification links, or exploit details in a public issue.

Include the affected revision, reproduction steps, expected impact, and any suggested mitigation. This is a non-commercial archived project, so no response time or bug-bounty payment is guaranteed.

## Previously exposed credentials

Removing a secret from the current tree or rewriting Git history does not revoke it. Any credential that has ever been committed must be disabled or rotated with its provider before the repository is published.
